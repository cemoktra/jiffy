# Jiffy

Jiffy is a fork of the [Warp](https://github.com/warpdotdev/warp) terminal with all cloud features
removed (no account, AI, sync, telemetry, or autoupdate) and [Jujutsu (jj)](https://github.com/jj-vcs/jj)
support added.

## Build

```bash
./script/bootstrap   # one-time setup
./script/run         # build and run
```
